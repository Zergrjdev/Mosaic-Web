Everything a game needs, in one workspace

Four kinds of page that link together, so the design lives in one place instead of five tools.

Design documents

Write your game design document, lore, quest scripts and balance notes with rich text, tables, callouts and toggles.

Systems boards

Map progression, economy, combat and content on boards with cards, columns and linked sub-boards.

Whiteboard

Sketch levels, encounters and player flows freely, then turn them into boards and docs.

UI and asset design

A free-form canvas with gradients, shadows, reference-resolution guides and grid snapping. No frames in the way.

Export for your engine

Every item as its own transparent image or one sprite atlas, with names, pivots and 9-slice borders in a layout file.

Your own storage

Projects live in Supabase projects you own. Connect several and choose where each one goes.

Work together live

Edit the same project at once from the website and the desktop and mobile apps.

Plugins

Add buttons, settings and export formats. Engine integrations are built on the same plugin system.

Built on trust

The boring promises that matter when it is your game.

You own your data

Your projects are stored in Supabase projects you control, not on a server we run for you.

No telemetry

No analytics, ads or tracking. Mosaic does not phone home to see how you use it.

No built-in AI

Mosaic has no AI of its own and sends nothing to an AI service. Reviewed plugins in the Plugin store can add features, and they stay off until you install them.
