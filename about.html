About Mosaic

Mosaic is a workspace for designing an entire game: the documents, the systems, the levels, and the interface, together in one place.

What you can do

  • Write the design. Game design documents, lore, quest scripts and balance notes in rich docs and tables.
  • Plan the systems. Boards for progression, economy, combat and content, with sub-boards that link together.
  • Sketch freely. A whiteboard for levels, encounters and flows.
  • Design the interface. A free-form UI and asset canvas with reference-resolution guides, a grid, gradients and shadows. No frames.
  • Export what the engine needs. Each item as its own transparent image, or one sprite atlas, with a layout file recording positions, pivots and 9-slice borders.
  • Work together. Edit the same project live, on the web or in the desktop and mobile apps.

Your data, and what leaves your device

Projects are stored in Supabase projects that you connect, not on a server we run for you. You can connect more than one and choose where each project goes. You can download or delete your account data from Settings at any time.

No telemetry. Mosaic contains no analytics, advertising or tracking code, and it does not phone home. Your browser or app talks only to: Mosaic’s account service (sign-in), the Supabase projects you connect (your data), a Discord webhook if you add one, and Google Fonts only if you choose a custom font inside a design. Interface fonts and icons are served from the site itself.

No AI built in

Mosaic has no AI of its own. Nothing is generated for you and nothing you write or draw is sent to an AI service. The Plugin store may offer plugins written by other people, including ones that connect to an AI service. They are reviewed before they are listed, they stay off until you install and turn them on, and each one shows the servers it can contact. Mosaic does not train any model.

How Mosaic was made

Mosaic was built with the help of AI tools (Anthropic’s Claude), which assisted with writing code and text. That is a statement about how the software was made. It does not mean the product has AI built in.

Sharing and Discover

Projects are private by default. You can make a project public and it will appear on Discover for anyone to view read-only. Remove it any time.

Extensible

Mosaic has a plugin system and a Plugin store: anyone with an account can submit a plugin, and it is listed once a reviewer approves it. Developers can read the Docs. Integrations for game engines are planned to build on it; none are available yet.
